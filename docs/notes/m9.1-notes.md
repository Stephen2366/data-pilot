## 验证素材

- 红灯：`pytest tests\test_m9_1_milvus_schema_retrieval.py ... pytest-m9_1-red` 2 failed，失败于 `MilvusVectorIndex` 仍抛 `NotImplementedError`。
- 探针：`pymilvus 3.0.0` 可用；`MilvusClient(uri="http://127.0.0.1:19530").list_collections()` 可连接；旧 ORM API 有 deprecation warning。
- 真实 Milvus 坑：`VARCHAR` 主键必须显式 `max_length`，快速 `create_collection(id_type="string")` 会报 `type param(max_length) should be specified`；改用显式 schema + `AUTOINDEX`。
- 稳定性坑：不能用 Python 内置 `hash()` 做 dense vector 维度映射，因为进程级随机盐会让 Milvus 排序不可复现；已改为 SHA1 稳定 hash。
- 绿灯：`pytest tests\test_m9_1_milvus_schema_retrieval.py tests\test_phase3a_schema_retrieval.py ... pytest-m9_1-related` 8 passed，1 个既有 Starlette/httpx warning。
- Smoke：`python scripts\smoke_m9_1_milvus.py` 成功，报告 `.agent_work/temp/m9_1-milvus-smoke.md`。
- Smoke 结论：Milvus + deterministic embedding 与 in-memory 召回数字完全一致：formal 15/15 tables、16/18 items、3/3 join；challenge 29/29 tables、29/33 items、6/6 join；diagnostic 54/54 tables、54/62 items、14/14 join。
- 全量回归：`$env:OPENBLAS_NUM_THREADS='1'; pytest -p no:cacheprovider --basetemp=.agent_work/temp/pytest-m9_1-full` 52 passed，1 个既有 Starlette/httpx warning。
- `git diff --check`：无 whitespace error，仅 Windows LF→CRLF 提示。
- 初步建议：adapter 可保留在实验分支，但当前没有召回质量收益；若要合入主线，建议先接真实中文 embedding（BGE/text2vec）再复测。
