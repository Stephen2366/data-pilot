**1. 运行证据复用**

```
RAG 进入生产后，新增能力不能只看功能是否可用，还要看运行证据能否被不同角色复用。平台需要把引用片段、文档版本、召回得分、权限过滤、生成摘要和用户反馈记录成稳定字段，并和发布单、Trace、评测样本以及事故记录关联起来。这样一次线上问题发生后，团队可以沿着同一组事实判断影响范围、责任归属和修复顺序，而不是在模型日志、业务日志和人工说明之间来回拼接。
```
