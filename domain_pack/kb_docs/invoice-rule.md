# 发票开具规则

平台支持电子普通发票和增值税专用发票。可开票金额以订单实付金额为准，不使用商品标价、GMV 或退款前金额替代。

需要红冲重开的，应在原发票开具后 7 天内申请，并提供能够定位原订单和发票的信息。某张订单当前是否可重开属于实时业务事实，应查询订单与发票系统。
