# 基础退款政策

平台支持 7 天无理由退货、经确认的质量问题退款、物流损坏退款和符合规则的价保补差。申请人需要提供可定位订单的订单号；不同原因所需证据和处理方式以对应专项规则为准。

质量问题的认定范围、证据和退款处理见“质量问题退款规则”，不得仅凭本总则直接判定质量责任。
