# 高价值客户服务规则

客户在最近连续 12 个月内的累计实付消费金额超过 20000 元时，满足 VIP 通道资格规则，可享受专属客服和延长退货窗口。

本文只定义资格口径，不记录任何客户是否已经达标。判断具体客户资格时，必须以查询时点的订单事实计算，并由未来 SQL Evidence 与本文档 Evidence 共同支持。
