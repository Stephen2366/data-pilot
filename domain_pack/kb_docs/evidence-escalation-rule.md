# 证据不足与人工复核规则

申请材料不足、关键信息相互矛盾，或者现有专项规则无法覆盖当前情况时，应明确说明缺少什么，并请求最小必要补充材料或转人工复核。在完成核实前，不自动承诺退款、补偿、取消、重开票或其他处理结果。

本文只处理“证据不足或规则无法确定”的兜底流程，不提高任何专项规则的默认材料要求。质量问题、物流延迟、发票等专项规则已经明确材料或判断条件时，仍按对应专项规则执行。
